# 0x00 HAM 组合结构

## 组合基本用法

在 HAM 中，可以用 `{}` 来声明组合，用 `,` 来分隔键值对，例如：

```HAM
{ x = 1, y = 2 }
```

就代表一个组合，称为组合的声明式。可以通过 `.` 来获取组合中的元素：

```HAM
{ x = 1, y = 2 }.x   // 1
```

组合的声明式可以作为“值”赋给键：

```HAM
{
  comb = { x = 1, y = 2 },
  val = comb.x                // 1
}
```

从上面的例子我们还可以发现：

- 组合内的元素可以在声明后被直接使用，效果等同于声明时 `=` 后的表达式
- 组合内的元素不能在组合外访问

> 提示：上面的那些看起来像是变量的东西实际上不应该称为变量，而是一个表达式的别名，因为函数式下任何值都是不可变的。

HAM 的源代码文件本身就是一个巨大的组合，但是最外面的 `{}` 可以省略。

文件

```HAM
{
  a = 1,
  b = 2,
  c = 3
}
```

可以直接写成：

```HAM
a = 1,
b = 2,
c = 3
```

当然，HAM 允许省略掉键值对间的 `,`：

```HAM
a = 1
b = 2
c = 3
```

## 键名

键名是一个标识符，符合正则表达式：

```
(?:[A-Za-z#][A-Za-z0-9_#]*|_[A-Za-z0-9_#]+)
```

即以字母或 `#` 开头，后面可以跟字母、数字、下划线或 `#`；或者以下划线开头，但后面必须至少跟一个字符。数字不能开头。单独的 `_` 不能作为键名。

```HAM
{
  a = 1,
  _private = 2,  // 下划线开头可以
  #curArgc = 3,  // # 开头可以
  _ = 4          // 不可以：_ 是语法糖参数
}
```

> 提示：`//` 是 ham 的单行注释，`/* ... */` 是多行注释。

以 `#` 开头的键名表示私有键，不可在外部被 `.` 访问。

> 提示：HAM 建议使用驼峰命名法。

## 键名的覆写

在组合中可以对同一个键名进行多次声明，称为覆写，在覆写后以后者为准：

```HAM
x = 1,      // 1
x = x + 1   // 2
```

甚至可以“覆写组合内的元素”：

```HAM
comb = { x = 1, y = 2 },
comb.x = 2
```

如果将键覆写成空组合，原来的值将被删除，相当于删除了该键：

```HAM
comb = { x = 1, y = 2 },
comb.x = {},
```

此时 `comb` 变为 `{ y = 2 }`。

## 组合的提取和扩展

可以用类似覆写的方法扩展组合：

```HAM
comb = { x = 1, y = 2 },
comb.z = 3
```

如果想要用一个组合扩展另一个组合，则可以使用提取元素的方法。

提取元素（按键名把组合中的元素拿出来以直接使用）：

```HAM
{x, y} = comb   // 相当于 x = comb.x, y = comb.y
```

用组合扩展组合：

```HAM
comb1 = { a = 3, b = 4 },
comb.{a, b} = comb1
```

此外，组合的扩展也可以使用一种算符 `<|` （Δ 算符），上述组合扩展可以写为：

```HAM
comb = comb <| comb1 // { a = 3, b = 4 }
```

> 提示：用顺序匹配键的方式理解这种表达法，优先匹配 comb1 中的键

扩展时也可能会发生覆写：

```HAM
comb2 = { a = 1, c = 2 },
comb1 = comb1 <| comb2      // { a = 1, b = 4, c = 2 }
```

## 键的多面

在 HAM 中，一个键可以同时有组合面和值面，这个键既可以当作一个组合来用，也可以当作一个值来用。

我们用 `<|` 运算符来实现这样的功能（也就是在组合基本用法末尾的那个 `sth`）：

```HAM
sth = 1 <| { element = 2 }, // 1 或 { element = 2 }
a = sth + 1,                // 2
b = sth.element + 1         // 3
```

这表明了组合与值是不一样的。组合不能简单地被视作一个“值”。

## 键的投影

用 `.` 来获取组合中的键称为键的投影。除了直接显式投影外，HAM 还支持隐式投影：

```
c = sth.element,    // 显式投影
d = sth <| .element // { element = 2 } <| 2
                    // 此处 element 投影的是它前面的组合里的 element 键
```
