# 0x01 HAM 函数

函数是 HAM 的一等公民，HAM 用函数来表达运算。

## 函数的声明

函数的声明式用 `() => ` 的形式表示，`()` 中为参数列表， `=>` 后为函数值：

```HAM
one = () => 1, // 注意它是一个函数，而不是一个值
inc = x => x + 1, // 单参时，括号可以省略
add = (x, y) => x + y,
curriedAdd = (x) => (y) => x + y
```

HAM 提供了一个语法糖来简化单参函数的声明。用 `_` 代替参数，用 `` ` `` 划定范围：

```HAM
inc     = `_ + 1`        // 等价于 inc     = x => x + 1
xAndInc = `_ <| `_ + 1`` // 等价于 xAndInc = x => (x <| y => y + 1)
```

反引号须成对嵌套，优先匹配符合词法规则的反引号。反引号内必须出现 `_`，`_` 也必须被反引号包裹。内层 `_` 绑定内层函数。字符串字面量的反引号不参与配对。

函数的参数也可以匹配组合：

```HAM
addxy = ({ x, y }) => x + y
```

用 `<-` 以声明一个可以递归调用的函数，在 `<-` 后可以使用正在被定义的键。具体示例见后文。

## 函数的调用

在 HAM 中，函数的**调用**指一个**函数**与一个**结构**作 `$` 运算。

**结构**是被 `()` 包裹的参数列表，值与值间用 `,` 隔开。结构内的值是函数的参数。

为了方便，HAM 也允许省略 `$` 运算符，直接用括号调用函数：

```HAM
a = 1,
b = inc $ (a),              // 2
c = add(a, b),              // 3
d = (x => x * x)(2)         // 4 注意函数的声明式可以直接调用
e = addxy({ x = 3, y = 2 }) // 5
```

当函数的调用不合法（参数数量不匹配、参数类型不符合等）时，函数值为空组合 `{}`：

```HAM
a = add(1),          // {}
b = add(1, 2, 3)     // {}
c = addxy({ x = 3 }) // {}
```

> 提示：空组合其实就是无法使用的值，因为它没有元素，也不能当作值

还可以用 `|>` 运算符来进行管道式调用，管道调用只允许单参函数，`x |> f` 相当于 `f (x)`。管道的优先级低于 `$` 函数调用：

```HAM
a = 1,
b = a |> inc,          // 2
c = a |> inc |> inc,   // 3
d = b |> (x => x * x), // 4
e = a |> `add(_, c)`,  // 4
d = e |> a,            // {}
```

管道搭配单参数函数语法糖可以实现连续定点插入参数：

```HAM
legs = (chicken, rabbit) => chicken * 2 + rabbit * 4,
square = x => x * x,
a = 2 |> `legs(_, 3)`           // 16
b = 3 |> `legs(2, _)`           // 16
c = 2 |> `legs(_, _)` |> square // 144
```

注意只有函数才可以被调用。一个非函数如果被调用，会返回空组合 `{}`。

## 函数的不完全柯里化

在 HAM 中，函数可以接受比声明的参数更多的参数，这些多余的参数会给函数的返回值继续调用。它的本质是结构的分裂。

```HAM
weirdFn = (a, b) => (c) => (d, e) => a + b + c + d + e,
a = weirdFn $ (1)             // {}
b = weirdFn $ (1, 2)          // (c) => (d, e) => 1 + 2 + c + d + e
c = weirdFn $ (1, 2, 3)       // (d, e) => 1 + 2 + 3 + d + e
d = weirdFn $ (1, 2, 3, 4)    // {}
e = weirdFn $ (1, 2, 3, 4, 5) // 15
```

> 提示：`c` 的本质是 `weirdFn $ (1, 2) $ (3)`，即 `b $ (3)`；`d` 的本质是 `c $ (4)`，参数数量不匹配，所以 `d` 的值为空组合 `{}`。

## 函数与 `<|` 算符

是时候介绍 `<|` 算符的另一个用途了，除了扩展组合之外，`<|` 也可用于组合和值之间甚至连接两个值、两个既可以当作值也可以当作组合的东西（在 HAM 里这种东西广泛存在）：

```HAM
x = 1 <| { x = 2 },   // 1 或 { x = 2 }
y = { x = 2 } <| 1    // 1 或 { x = 2 }
```

可见值和组合的顺序不重要。

如果两个都是值，则 `<|` 运算会遵循覆写原则。正如 `<|` 是一个向左的箭头一样，覆写也是从右向左的：

```HAM
x = 1 <| 2,   // 2
y = 2 <| 1    // 1
```

混合使用：

```HAM
x = (1 <| { x = 1, y = 2 }) <| (2 <| { x = 2, z = 3 })
  // 2 或 { x = 2, y = 2, z = 3 }
```

可以将两个函数用 `<|` 连接，相当于新的函数，这个函数的行为是把参数分别带入左边和右边的函数，得到“值或者组合”，然后再把这些“值或者组合”按上述规则合并。

写一个函数返回其参数个数对 3 取余的值（新语法会有介绍），`<|` 运算符的优先级低于函数声明的优先级，所以可以写成：

```HAM
argcMod3 <- 0 <| () => 0 <| (x) => 1 <| (x, y) => 2 <| (x, y, z) => argcMod3
a = argcMod3 $ (),          // 0
b = argcMod3 $ (m),         // 1
c = argcMod3 $ (m, n),      // 2
d = argcMod3 $ (m, n, p),   // 0 <| argcMod3
e = argcMod3 $ (m, n, p, q) // 1
```

注意 `d` 的结果不是纯值 `0`。3 个参数恰好完整命中 `(x, y, z) => argcMod3` 分支，返回的是 `argcMod3` 本身，于是结果合并了值面 `0` 与函数面 `argcMod3`，即 `0 <| argcMod3`。当把 `d` 当值用时得到 `0`，当函数调用时与调用 `argcMod3` 等价——例如 `d $ (q)` 与 `argcMod3 $ (q)` 一样，结果是 `1`。

```HAM
// 展开 argcMod3 $ (m, n, p, q) 的计算过程
e = argcMod3 $ (m, n, p, q)
  = 0                       $ (m, n, p, q) <|
    (() => 0)               $ (m, n, p, q) <|
    ((x) => 1)              $ (m, n, p, q) <|
    ((x, y) => 2)           $ (m, n, p, q) <|
    ((x, y, z) => argcMod3) $ (m, n, p, q)
  = {}                      <|
    0        $ (m, n, p, q) <|
    1        $ (n, p, q)    <|
    2        $ (p, q)       <|
    argcMod3 $ (q)
  = {}                            <|
    {}                            <|
    {}                            <|
    0                       $ (q) <|
    (() => 0)               $ (q) <|
    ((x) => 1)              $ (q) <|
    ((x, y) => 2)           $ (q) <|
    ((x, y, z) => argcMod3) $ (q)
  = {} <| {} <| {} <|
    {}             <|
    0 $ (q)        <|
    1              <|
    {}             <|
    {}
  = {} <| {} <| {} <| {} <| {} <| 1 <| {} <| {}
  = 1
```

利用这些规则可以创建一些复杂的函数。

`<|` 链从左到右求值，各成分的结果依次并入累积合并。求值到某个成分时，可以用 `.x` 获取左侧**组合**中的键 `x`：

```HAM
comb = { x = 1 } <| .x    // { x = 1 } <| 1
```

如果左侧是**函数**，则 `.x` 能获取到值，当且仅当左侧函数被调用后能返回一个有 `x` 键的组合，否则 `.x` 为空组合 `{}`：

```HAM
getA = () => { a = 1 },
getB = () => { b = 2 },
f = getA <| getB <| () => .a + .b,

f()  // { a = 1 } <| { b = 2 } <| 3，值的部分为 3
```

调用 `f()` 时，三个函数面都收到空结构：`getA()` 求出 `{ a = 1 }`，`getB()` 求出 `{ b = 2 }`，第三个成分体内的 `.a`、`.b` 投影累积合并（即前两个成分的调用结果），`.a + .b` 求出 `3`。

## 临时组合

用 `let in` 或 `where` 可以声明一个临时组合，临时组合的作用域只在 `in` 或 `where` 后的表达式中有效，且会临时覆盖外部键名。

在访问临时组合的键时，无需用 `.` 运算符，直接用键名即可隐式投影：

```HAM
let { x = 1, y = 2 } in x + y, // 3
x + y where { x = 1, y = 2 },  // 3

{ a = 1 } <| let { a = 2 } in .a + a, // 3
a = 1,
a where { a = 2 } // 2

comb = { x = 1, y = 2 },
x + y where comb              // 3
x + y where comb <| { x = 3 } // 5
```
