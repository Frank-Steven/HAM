# 0x01 HAM 函数

函数是 HAM 的一等公民，HAM 用函数来表达运算。

## 函数的声明

函数的声明式用 `() => ` 的形式表示，`()` 中为参数列表， `=>` 后为函数值：

```HAM
one = () => 1, // 注意它是一个函数，而不是一个值
inc = x => x + 1, // 单参时，括号可以省略
add = (x, y) => x + y,
curriedAdd = (x) => (y) => x + y
```

当然，`_` 作为语法糖可以简化单参函数的声明：

```HAM
inc = _ + 1 // 等价于 inc = (someParamName) => someParamName + 1
```

函数的参数可以匹配组合：

```HAM
addxy = ({ x, y }) => x + y
```

用 `<-` 以声明一个可以递归调用的函数，在 `<-` 后可以使用正在被定义的键。具体示例见后文。

注意分开无参函数和值。具体来说，`one` 是一个函数，而不是一个值 `1`。要得到 `1`，需要调用它：`one()`。

## 函数的调用

使用 `$` 运算符可以调用函数。函数的参数被 `()` 包裹，称为一个**结构**，结构才是函数真正的参数。`$` 运算符的优先级高于 `<|` 运算符。

当然，你也可以省略掉 `$` 运算符，直接用括号调用函数：

```HAM
a = 1,
b = inc $ (a),              // 2
c = add(a, b),              // 3
d = (x => x * x)(2)         // 4 注意函数的声明式可以直接调用
e = addxy({ x = 1, y = 2 }) // 3
```

当函数的调用不合法时，函数值为空组合 `{}`：

```HAM
a = add(1),          // {}
b = add(1, 2, 3)     // {}
c = addxy({ x = 1 }) // {}
```

> 提示：空组合其实就是无法使用的值，因为它没有元素，也不能当作值

被调用者不是函数时，情况略有不同，只要结构为空，调用就返回被调用者自身：

```HAM
x = 0(),         // 0
comb = { x = 1 },
y = comb(),      // { x = 1 }
z = 0(1)         // {} 结构非空时仍然不合法
```

还可以用 `|>` 运算符来进行管道式调用，`|>` 运算符与 `<|` 同级（见 0x07），低于函数调用：

```HAM
a = 1,
b = a |> inc $ (),         // 2
c = a |> add $ (b, 3),     // 6
d = 2 |> (x => x * x) $ () // 4
e = a |> inc() |> add(3)   // 5
```

`|>` 运算符是一个语法糖，它的作用是把左侧的值作为结构传给右侧的函数（或函数调用），插入为结构的第一个参数。`a |> f $ (b, c)` 等价于 `f(a, b, c)`，`a |> f()` 与 `a |> f` 都等价于 `f(a)`。`|>` 左结合，且与 `<|` 同级：`x <| y |> f()` 等价于 `(x <| y) |> f()`——管道读取左侧的完整表达式；`a |> f() |> g()` 等价于 `(a |> f()) |> g()`。

## 函数与 `<|` 算符

是时候介绍 `<|` 算符的另一个用途了，除了扩展组合之外，`<|` 也可用于组合和值之间甚至连接两个值、两个既可以当作值也可以当作组合的东西（在 HAM 里这种东西广泛存在）：

```HAM
x = 1 <| { x = 2 },   // 1 或 { x = 2 }
y = { x = 2 } <| 1    // 1 或 { x = 2 }
```

可见值和组合的顺序不重要。

如果两个都是值，则 `<|` 运算会遵循覆写原则：

```HAM
x = 1 <| 2,   // 2
y = 2 <| 1    // 1
```

混合使用：

```HAM
x = (1 <| { x = 1, y = 2 }) <| (2 <| { x = 2, z = 3 })
  // 2 或 { x = 2, y = 2, z = 3 }
```

可以将两个函数用 `<|` 连接，相当于新的函数，这个函数的行为是把参数分别带入左边和右边的函数，得到“值或者组合”，然后再把这些“值或者组合”按上述规则合并。

写一个函数返回其参数个数对 3 取余的值（新语法会有介绍），`<|` 运算符的优先级低于函数声明的优先级，所以可以写成：

```HAM
argcMod3 <- 0 <| () => 0 <| (x) => 1 <| (x, y) => 2 <| (x, y, z) => argcMod3
a = argcMod3 $ (),          // 0
b = argcMod3 $ (m),         // 1
c = argcMod3 $ (m, n),      // 2
d = argcMod3 $ (m, n, p),   // 0 <| argcMod3
e = argcMod3 $ (m, n, p, q) // 1
```

注意 `d` 的结果不是纯值 `0`。3 个参数恰好完整命中 `(x, y, z) => argcMod3` 分支，返回的是 `argcMod3` 本身，于是结果合并了值面 `0` 与函数面 `argcMod3`，即 `0 <| argcMod3`。当把 `d` 当值用时得到 `0`，当函数调用时与调用 `argcMod3` 等价——例如 `d $ (q)` 与 `argcMod3 $ (q)` 一样，结果是 `1`。

注意到 `e` 的声明中用了 4 个参数给 argcMod3 函数，为什么得到了 1？

这就要提到一种“不完全柯里化”了，意思就是当参数列表中的参数过多时，会从左往右取出需要数量的参数，剩下的留在括号里传给返回值（返回的函数），但是这不意味着任何函数都接受任意数量的参数，当括号里的参数不够时，函数会直接返回 `{}` ，而当函数返回非函数后括号里还有参数，也会返回 `{}`，这两种调用为非法调用。除了把参数写在一个括号里，连续使用括号进行调用也是可以的，有时这两种方法是等价的，有时则不同，这是因为结构被分割的位置不同。

```HAM
// 等价形式推导过程
e = argcMod3 $ (m, n, p, q)
  = argcMod3 $ (m) $ (n, p, q) <|
    argcMod3 $ (m, n) $ (p, q) <|
    argcMod3 $ (m, n, p) $ (q)
  = 1 $ (n, p, q) <|
    2 $ (p, q)    <|
    argcMod3 $ (q)
  = {} <| {} <| 1
  = 1
```

可以发现，不完全柯里化可以把结构分割开，两结构之间再用 `$` 运算符连接。

利用这些规则可以创建一些复杂的函数。

`<|` 链从左到右求值，各成分的结果依次并入累积合并。求值到某个成分时，可以用 `.x` 获取左侧**组合**中的键 `x`：

```HAM
comb = { x = 1 } <| .x    // { x = 1 } <| 1
```

如果左侧是**函数**，则 `.x` 能获取到值，当且仅当左侧函数被调用后能返回一个有 `x` 键的组合，否则 `.x` 为空组合 `{}`：

```HAM
getA = () => { a = 1 },
getB = () => { b = 2 },
f = getA <| getB <| () => .a + .b,

f()  // { a = 1 } <| { b = 2 } <| 3，值的部分为 3
```

调用 `f()` 时，三个函数面都收到空结构：`getA()` 求出 `{ a = 1 }`，`getB()` 求出 `{ b = 2 }`，第三个成分体内的 `.a`、`.b` 投影累积合并（即前两个成分的调用结果），`.a + .b` 求出 `3`。

## 临时组合

用 `let in` 或 `where` 可以声明一个临时组合，临时组合的作用域只在 `in` 或 `where` 后的表达式中有效，且会临时覆盖外部键名。

在访问临时组合的键时，无需用 `.` 运算符，直接用键名即可隐式投影：

```HAM
let { x = 1, y = 2 } in x + y, // 3
x + y where { x = 1, y = 2 },  // 3

{ a = 1 } <| let { a = 2 } in .a + a, // 3
a = 1,
a where { a = 2 } // 2

comb = { x = 1, y = 2 },
x + y where comb              // 3
x + y where comb <| { x = 3 } // 5
```
