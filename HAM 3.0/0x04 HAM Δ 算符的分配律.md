# 0x04 HAM Δ 算符的分配律

Δ 算符 `<|` 对组合满足分配律（⊕ 表示任意二元算符）

```HAM
  (a <| b) ⊕ c
= a ⊕ c <| b ⊕ c
```

`c` 可以是任何表达式

```HAM
  (a <| b) ⊕ (c <| d)
= (a ⊕ (c <| d)) <| (b ⊕ (c <| d))
```

```HAM
  (a <| b) ⊕ x => x + 1
= (a ⊕ x => x + 1) <| (b ⊕ x => x + 1)
```

`<|` 对任何稳定的 Something 满足分配律

对于不稳定的 Something，则视为一个大函数。调用时，`<|` 两侧的表达式同时接收参数，每侧各自进行不完全柯里化，直到左侧稳定，用分配律变成稳定 Something。

## Something 标准式

Something 的标准式由纯稳定块与纯不稳定块交替组成：

```
... <| [不稳定 Something] <| [稳定 Something] <| [不稳定 Something] <| [稳定 Something] <| ...
```

- **稳定 Something**：标准形式中不含函数，仅剩 `[组合] <| [值]`
- **不稳定 Something**：标准形式中包含至少一个函数

## 调用时的不完全柯里化

调用不稳定 Something 时，`<|` 两侧各自独立进行不完全柯里化：

- 参数多于形参：取出所需数量，剩余参数传给返回值
- 参数等于形参：完全匹配，正常返回
- 参数少于形参：匹配失败，返回 `{}`
- 返回值非函数但仍有剩余参数：返回 `{}`
- 稳定的 Something：结构为空则返回自身，结构非空则返回 `{}`

这个过程持续**直到左侧稳定**——即左侧不再有未消耗完参数的函数，所有左侧表达式已完全求值为值或组合。此时用分配律将所有结果合并为稳定 Something。

以 argcMod3 函数为例。

```HAM
argcMod3 <- 0 <| () => 0 <| x => 1 <| (x, y) => 2 <| (x, y, z) => argcMod3
```

调用 `argcMod3(m, n, p, q)`（4 个参数），每个分支独立进行**不完全柯里化**：

```HAM
// 第一轮：4 个参数
0                       $ (m, n, p, q) = {}
(() => 0)               $ (m, n, p, q) = {}
(x => 1)                $ (m, n, p, q) = 1 $ (n, p, q) = {}
((x, y) => 2)           $ (m, n, p, q) = 2 $ (p, q)    = {}
((x, y, z) => argcMod3) $ (m, n, p, q) = argcMod3 $ (q)
// 最终结果为 {} <| {} <| {} <| argcMod3(q) = argcMod3(q)

// 第二轮：argcMod3(q)，1 个参数
0                       $ (q) = {}
(() => 0)               $ (q) = {}
(x => 1)                $ (q) = 1 // 稳定
((x, y) => 2)           $ (q) = {}
((x, y, z) => argcMod3) $ (q) = {}
// 最终结果为 {} <| {} <| 1 <| {} <| {} = 1
```

3 个参数的情形：`argcMod3 $ (m, n, p)` 恰好完整命中三分支，没有剩余参数：

```HAM
// 唯一存活的分支
((x, y, z) => argcMod3) $ (m, n, p) = argcMod3 // 不稳定，无剩余参数
// 其余分支：0 $ (m, n, p) = {}，（() => 0）$ (m, n, p) = {}，
//          (x => 1) $ (m, n, p) = 1 $ (n, p) = {}，（(x, y) => 2）$ (m, n, p) = 2 $ (p) = {}
// 最终结果为 {} <| {} <| {} <| {} <| argcMod3 = argcMod3，即 0 <| argcMod3（值面 0、函数面 argcMod3）
```

结果不是纯值 `0`，而是含值面 `0` 与函数面 `argcMod3` 的不稳定 Something。若继续调用，剩余结构会交给函数面，例如 `argcMod3 $ (m, n, p) $ (q) = (0 <| argcMod3) $ (q) = 0 $ (q) <| argcMod3 $ (q) = {} <| 1 = 1`，与 `argcMod3 $ (q)` 一致。

两个函数用 `<|` 连接时，参数同时传给两个函数，直到左侧稳定，用分配律变成稳定 Something。

```HAM
  (a <| b) <| c
= (a <| c) <| (b <| c)
```

上述等式成立。
