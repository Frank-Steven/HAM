# 0x07 HAM 运算符及其重载

HAM 的运算符是语法糖，本质是二元函数，以下两种写法等价：

```HAM
a + b
```

```HAM
`+(a, b)
```

运算符函数可以被覆写：

```HAM
`+ = (a, b) => a * b
```

这样就把加号变成了乘法。

但我们更多时候需要扩展算符的功能：

```HAM
`+ = `+ <| (a:MySet, b:MySet) => ...
```

用 Δ 算符搭配带有定义域的函数轻松扩展符号的功能，并不破坏原有功能。

### 运算符优先级一览

| 优先级（从松到紧） | 运算符                              | 概述                   |
| ------------------ | ----------------------------------- | ---------------------- |
| 1                  | `=`、`<-`                           | 声明                   |
| 2                  | `in`、`notin`、`subseteq`、`subset` | 集合的判定             |
| 3                  | `let in`、`where`                   | 临时组合               |
| 4                  | `\|>`                               | 管道调用               |
| 5                  | `<\| `、`<~`                        | Something 或集合的扩展 |
| 6                  | `=>`、`_`                           | 函数声明               |
| 7                  | `\|\|`                              | 逻辑或                 |
| 8                  | `&&`                                | 逻辑与                 |
| 9                  | `\|`、`&`                           | 集合并/交、数组过滤    |
| 10                 | `==`、`!=`、`<`、`>`、`<=`、`>=`    | 比较                   |
| 11                 | `+`、`-`                            | 算术、拼接、差集       |
| 12                 | `*`、`/`、`%`                       | 算术                   |
| 13                 | `!`、`~`                            | 否定、补集             |
| 14                 | `.`、`[]`、`$`、`f(...)`            | 投影、下标、调用       |
