# 0x07 HAM 运算符及其重载

> [!WARNING]
>
> 不建议随意操作运算符。

HAM 的运算符是语法糖，本质是二元函数，以下两种写法等价：

```HAM
a + b
```

```HAM
#+(a, b)
```

运算符函数可以被覆写：

```HAM
#+ = (a, b) => a * b
```

这样就把加号变成了乘法。

但我们更多时候需要扩展算符的功能：

```HAM
#+ = #+ <| (a:MySet, b:MySet) => ...
```

用 Δ 算符搭配带有定义域的函数轻松扩展符号的功能，并不破坏原有功能。

注意这些运算符都以 `#` 开头，在组合外部无法访问。

### 运算符优先级一览

| 优先级（从松到紧） | 运算符                             | 概述                             |
| ------------------ | ---------------------------------- | -------------------------------- |
| 1                  | `=`、`<-`                          | 声明                             |
| 2                  | `is`、`isnt`、`subseteq`、`subset` | 集合的判定                       |
| 3                  | `let in`、`where`                  | 临时组合                         |
| 4                  | `\|>`、`<\| `、`<~`                | 管道调用、Something 或集合的扩展 |
| 5                  | `=>`                               | 函数声明                         |
| 6                  | `\|\|`                             | 逻辑或                           |
| 7                  | `&&`                               | 逻辑与                           |
| 8                  | `\|`、`&`                          | 集合并/交、数组过滤              |
| 9                  | `==`、`!=`、`<`、`>`、`<=`、`>=`   | 比较                             |
| 10                 | `+`、`-`                           | 算术、拼接、差集                 |
| 11                 | `*`、`/`、`%`                      | 算术                             |
| 12                 | `!`、`~`                           | 否定、补集                       |
| 13                 | `.`、`[]`、`$`、`f(...)`、`` ` ``  | 投影、下标、函数调用、语法糖定界 |
